# Yajir（ヤジール）

超小型MCU向けの、小さな組み込みスクリプト言語のリファレンス実装（純C）。

**「すべてはポート。`値 -> ポート` で値を流す」** ── この一つの発想だけで、
GPIO・UART・タイマ・文字列処理・イベントを、同じ記法で扱います。

```
MAIN
    1 -> LED1        // 点ける
    500 -> WAIT      // 500ms 待つ
    0 -> LED1        // 消す
    500 -> WAIT
END

ON BTN               // ボタン押下イベント
    "pushed!" -> STDOUT
END
```

- **ヒープ不使用** ── 固定RAMアリーナ1本だけで動く（`malloc` なし）
- **スタック型バイトコードVM** ＋ ワンパスコンパイラ ＋ 協調tick
- **ホスト非依存のコア** ── ボード側は「ポートを register するグルー」を差し替えるだけ
- 端末からスクリプトを貼り付け → その場でコンパイル＆常駐実行

## フットプリント（実測）

| | |
|---|---|
| **RAM** | 約 **10 KB**（VMアリーナ1本・ヒープ不使用。実機ローダは受信バッファ込みで約14 KB） |
| **Flash** | 約 **24 KB**（Cortex-M4 コア一式。デバッグビルド実測、最適化でさらに小さく） |
| **動作実績** | STM32 NUCLEO-L476RG（Cortex-M4）── Lチカ / ボタン / フィボナッチ ほか |

バイトコード2 KB・文字列プール1 KB・スロット/ポート数などは `src/core/script_config.h` で調整できます。

## 収録物

- `src/core/` ── 言語コア（VM・コンパイラ・スケジューラ・文字列ユーティリティ）
- `src/host/` ── PC（Windows）ホストと STM32 実機ホスト
- `tests/`    ── フェーズ別ユニットテスト
- `docs/` / `scripts/` ── 組み込みポート早見表とサンプルスクリプト（`.yaj`）

### 変更履歴（v0.4.8 → v0.4.9）

**現場要望まとめ**——実機で出た小粒な使い勝手要望を3点。(1)(2) は純コンパイル時糖衣（**新opcodeゼロ・バイトコード不変・実行時コストゼロ・追加RAMゼロ**）、(3) は文字列ユーティリティ1本。

**(1) 行継続 `\`（バックスラッシュ＋改行）**——長い文・長い構造化文字定数を物理行に折り返して書けるようにする。

- `\` の直後が改行なら**論理行を継続**する（バックスラッシュ・改行〈CRLF は1改行に畳む〉・**次行の行頭水平空白**をまとめて消す。行番号は進める）。効き方は文脈で変わる:
  - **文字列の外**——`T_NEWLINE` を出さずに次行へつなぐ。文の途中どこでも折り返せる（`def_alias(NAME, \`〈改行〉、引数リストの途中 `A, B, \`〈改行〉`C -> MAP`、チェインの `->` 直前で切る等）。
  - **文字列の中**——文字列を継続し、**行頭のインデントを値に含めない**（整形の字下げが値を汚さない）:
    ```
    def_alias(CONV_TABLE, "xxxx|\
                           yyyy|\
                           zzzzzzz")      // == "xxxx|yyyy|zzzzzzz"
    ```
- 意味論: 行頭空白は**捨てる**（単一行版と厳密に同値）。意図的な空白は `\` の“前”に置けば残る。折り返す各物理行の末尾に `\` が要る。**裸の改行（`\` なし）は従来どおりエラー**（文字列は明示継続しない限り1行）。意味を与える対象（文字列内 `\`+改行／文字列外の裸 `\`）はどちらも現状エラーになる並びゆえ**後方互換**（有効な既存スクリプトは1つも挙動が変わらない）。

**(2) ビルド設定定数 `CFG_*` をスクリプトから参照可能に**——スロット数・文字列長をプラットフォーム非依存で書ける。

- `CFG_*` を式の値位置で **int リテラルへ展開**するコンパイル時定数。値は「そのビルドの `script_config.h` の実値」。だから移植先の設定に自動追従する:
  ```
  CFG_VAR_COUNT -> REPEAT
      ITR -> VAR              // VAR[0..CFG_VAR_COUNT-1] を過不足なくなめる
  END
  ```
- **ポートも alias スロットも消費しない**（`def_const`／`def_alias` とは別枠。使わない人のコストゼロ）。**読み取り専用**・**予約名**（`def_alias` で上書き不可）。公開は移植に要る**「寸法」定数14個に限定**（スロット数・文字列長・資源スロット数。内部限界 `CFG_CODE_SIZE`/`CFG_INSTR_BUDGET` 等は非公開）。

**(3) 文字列ユーティリティ `ASC`（文字→数値）を追加**——`CHR`（int→1文字str）の対。

- `"A" -> ASC` → `65`。**文字列の先頭1バイトを 0..255 で返す。空文字列は 0**（`RESULT` 産出）。これまで欠けていた「文字→数値」の一発変換。`'A'` は Yajir では既に int なので `ASC` の入力は文字列が自然（`90 -> CHR -> ASC` == 90 で往復）。
