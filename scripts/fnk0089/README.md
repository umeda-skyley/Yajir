# FNK0089用Yajirスクリプト

Freenove FNK0089（4WD Car Kit for Raspberry Pi Pico (W)）を、YajirのPico 2 W
ホストと選択式スクリプトライブラリで制御するサンプルです。

ライブラリ本体は`scripts/lib/fnk0089/`にあります。試す機能に対応する`.yaj`を
YAJIRドライブのルートへ置いてから、同名のスモークテストを`autorun.yaj`として置くか、
USBシリアルから投入してください。

ドットマトリックスのティッカーを試す場合は、YAJIRドライブのルートへ
`fnkmat.yaj`と`fnkfont.yaj`を置き、`matrix_ticker.yaj`を`autorun.yaj`として置きます。
ファイルを更新した後はPico 2 Wを再起動してください。

| スモークテスト | 必要なライブラリ | 内容 |
|---|---|---|
| `motor_smoke.yaj` | `fnkmotor.yaj` | M1～M4を低速で順に正転・逆転 |
| `buzzer_smoke.yaj` | `fnkbuzz.yaj` | 2kHzの短い音を3回発音 |
| `line_smoke.yaj` | `fnkline.yaj` | 左・中央・右センサー値を周期表示 |
| `sonar_smoke.yaj` | `fnksonar.yaj` | 超音波センサーの距離をcm表示 |
| `matrix_smoke.yaj` | `fnkmat.yaj` | 16x8ドットマトリックスへ目を表示 |
| `matrix_ticker.yaj` | `fnkmat.yaj`、`fnkfont.yaj` | 任意の英字列を右から左へスクロール |

## ピン割当

| 機能 | GPIO |
|---|---|
| M1 | 18 / 19 |
| M2 | 21 / 20 |
| M3 | 7 / 6 |
| M4 | 9 / 8 |
| ブザー | 2 |
| ライン 左 / 中央 / 右 | 12 / 11 / 10 |
| 超音波 TRIG / ECHO | 4 / 5 |
| ドットマトリックス SDA / SCL | 4 / 5 |

モーターPWMは500 Hz、速度値は`-100..100`です。最初の確認では車輪を床から浮かせ、
車体の電源をすぐ切れる状態にしてください。組立や配線により前進方向が逆になる場合は、
`fnkmotor.yaj`内の該当モーターの2ピンを入れ替えて調整できます。

## ハードウェア上の制約

ブザーのGPIO2とM1のGPIO18/19はRP2350の同じPWM sliceを共有します。ブザーを2kHzで
鳴らすとM1側のPWM周波数にも影響するため、当面はモーター停止中だけ発音してください。

ドットマトリックスと超音波センサーは、どちらもGPIO4/5のコネクタを使います。
同時には装着せず、試す方だけを接続してください。

実行中に異常を感じた場合は`Ctrl+C`でYajirを停止するか、車体の電源を切ってください。

## ドットマトリックス実機仕様

FNK0089の表示器は8x8ユニットを左右へ2枚並べた、横16×縦8 pixelです。
`fnkmat.yaj`は実機確認済みの左右順、列方向、上下方向を吸収し、アプリへ左上原点の
`x=0..15`、`y=0..7`として公開します。

`matrix_ticker.yaj`は5x7フォントで`TICKER_TEXT`を右から左へ繰り返し表示します。
表示文字列、1列の時間、輝度は次のaliasで変更できます。

```yajir
def_alias(TICKER_TEXT, "HELLO WORLD!?")
def_alias(FRAME_MS, 80)

INIT
	8 -> _MATRIX_BRIGHT
END
```

フォントの列データは10進数です。文字列から取り出した数値は、`STRTOL`の第2引数へ
`10`を渡して変換します。省略すると16進解釈になり、字形が崩れます。
